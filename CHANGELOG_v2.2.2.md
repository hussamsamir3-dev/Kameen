# Kameen v2.2.2 — tuk-tuks on the main road
- A tuk-tuk reaching the checkpoint is itself a violation (they are banned from main roads/highways). The case gets a verified note and a cue, the driver pleads "it is only one kilometre", and the correct call is citation or impound (hold/handover): +70 XP and a **500 EGP fine collected**. Waving it through: −60 XP, combo lost, trust −2, a complaint in the shift mail.
- New shift directive "Tuk-tuks are banned from the main road: fine + impound" can appear in the bulletin.
- Tuk-tuks are rarer on the main road now (never in Sinai or the desert).
- Fixed a file-stamp issue that could make the boot check reload a script.
